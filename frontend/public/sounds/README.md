# Sonidos de Notificación para Klinip

Este directorio contiene los archivos de sonido para las notificaciones de la aplicación.

## Archivos Necesarios

Para que las notificaciones funcionen correctamente con sonido, necesitas agregar los siguientes archivos de audio MP3:

1. **notification.mp3** - Sonido general de notificación (predeterminado)
2. **appointment.mp3** - Sonido para recordatorios de citas
3. **medication.mp3** - Sonido para recordatorios de medicación
4. **urgent.mp3** - Sonido para notificaciones urgentes

## Especificaciones Recomendadas

- **Formato**: MP3 (compatible con todos los navegadores)
- **Duración**: 1-3 segundos
- **Volumen**: Normalizado a -3dB
- **Bitrate**: 128 kbps
- **Frecuencia de muestreo**: 44.1 kHz

## Recursos para Sonidos Gratuitos

Puedes descargar sonidos libres de derechos de:

- [Freesound](https://freesound.org/)
- [Zapsplat](https://www.zapsplat.com/)
- [SoundBible](http://soundbible.com/)
- [Notification Sounds](https://notificationsounds.com/)

## Creación de Sonidos

Si prefieres crear tus propios sonidos, puedes usar:

- [Audacity](https://www.audacityteam.org/) (gratuito)
- [LMMS](https://lmms.io/) (gratuito)
- [FL Studio](https://www.image-line.com/) (de pago)

## Implementación Temporal

Si no tienes archivos de sonido aún, la aplicación seguirá funcionando. Los sonidos son opcionales y las notificaciones se mostrarán de todos modos.

Como alternativa temporal, puedes usar la vibración del dispositivo (en móviles) que ya está implementada.
