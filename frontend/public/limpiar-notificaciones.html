Limpieza de Notificaciones

Herramienta para solucionar notificaciones duplicadas

⚠️ Importante
Esta herramienta eliminará todas las notificaciones programadas y reiniciará el sistema de notificaciones. Tendrás que iniciar sesión nuevamente.
⏳ Esperando acción...
📋 Qué hace esta herramienta:
1. Desregistra todos los Service Workers
2. Limpia el caché de la aplicación
3. Elimina notificaciones programadas
4. Limpia la base de datos de notificaciones
5. Te redirige a la aplicación limpia
